# Karla B. Sison — Portfolio

Personal portfolio site built with vanilla HTML, CSS, and JavaScript.
Project pages load as overlays using the fetch API, with no framework.

**Live:** https://floppy-cheese.github.io/my-website-portfolio/


## Contents

- `index.html` — about, projects, and CV
- `gabay.html`, `lifeline.html`, `pks.html` — project pages loaded into overlays
- `css/`, `js/`, `assets/` — styles, scripts, images
